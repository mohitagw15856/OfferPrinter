# 🖨 OfferPrinter

Paste one job description and your CV. Get a tailored CV, cover letter, fit
memo, ATS keyword report and interview prep pack — **without fabricating
anything**.

This Space runs in demo mode by default: it shows a real, previously generated
package so you can see exactly what the output looks like. To print your own,
paste an API key into the sidebar (Anthropic, OpenAI, Gemini or Moonshot). The
key is used for that one call and is never stored.

**The no-fabrication guarantee:** OfferPrinter never invents experience, skills,
employers, dates or metrics. When a role wants something you don't have, it says
so — the gap is flagged, not filled in. That is what makes the output safe to
actually send.

Free and open source (MIT):
<https://github.com/mohitagw15856/OfferPrinter>
